# Концепт приложения Zebra Coffee

**Сайт: https://zebra.makatova.com**

Интерактивный концепт мобильного приложения сети кофеен Zebra Coffee: QR и выгода сразу на главном экране, предзаказ, клуб и уровни, подарки за коины, сценарий «в моей кофейне нет воды». На странице есть переключатели сценариев, языка (русский / қазақша), светлой и тёмной темы, а также сравнение «Было / Стало» с текущей версией приложения.

## Важно

Это **неофициальный концепт**, сделанный постоянным гостем сети. Он **никак не связан с Zebra Coffee**: не согласован с компанией и не отражает её планы. Цены, адреса, уровни и условия — демонстрационные, нужны только чтобы показать идею. Оплата имитируется, время приготовления ускорено.

Автор — Элла Макатова.

## Как устроено

Весь прототип — один файл `index.html`: разметка, стили, логика и картинки (base64) внутри. Внешне подгружается только шрифт Onest с Google Fonts. Открывается в любом браузере, на телефоне разворачивается на весь экран.

Опубликовано через GitHub Pages (ветка `main`, корень репозитория).
